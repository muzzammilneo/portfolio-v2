## ✨ Features

- **Fixed Navigation Bar** — Logo, section links, and a "Book A Call" CTA
- **Hero Section** — Split layout with stats, headline, tagline, and a B&W portrait
- **Scroll Animation** — "Scroll down" indicator fades out as the user scrolls
- **Side Decorations** — Rotated role title and year accent text
- **Lightweight** — No frameworks or build tools; pure HTML, CSS, and JavaScript

## 🚀 Getting Started

No build step required — just open the project in a browser.

### Option 1: Direct Open

```bash
open index.html
```

### Option 2: Local Dev Server

```bash
# Using Python
python3 -m http.server 8000

# Using Node (npx)
npx -y serve .
```

Then visit `http://localhost:8000` in your browser.
